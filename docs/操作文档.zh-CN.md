# CodePilot 操作文档

## 1. 日常操作

### 1.1 初始化与提交需求

```bash
codepilot init .
codepilot "实现自动拆分和自动执行工作流"
```

### 1.2 任务状态与详情

```bash
codepilot status -p <项目名> -v
codepilot task show <task_id>
codepilot task logs <task_id> --tail 80
```

### 1.3 任务干预

```bash
codepilot task stop <task_id>
codepilot task retry <task_id>
codepilot task cancel <task_id>
codepilot task archive <task_id>
```

## 2. 项目级执行与巡检

### 2.1 执行队列

```bash
codepilot run -p <项目名>
codepilot daemon -p <项目名>
codepilot daemon -p <项目名> --status
codepilot daemon -p <项目名> --stop
```

### 2.2 巡检

```bash
codepilot inspect -p <项目名> --once
codepilot inspect -p <项目名>
codepilot inspect -p <项目名> --status
codepilot inspect -p <项目名> --stop
```

## 3. Web UI 运维

前台启动：

```bash
codepilot ui
```

后台服务：

```bash
codepilot ui start
codepilot ui status
codepilot ui logs --tail 100
codepilot ui stop
```

## 4. 发布操作

### 4.1 构建与安装

```bash
codepilot binary build
codepilot binary build --install
codepilot binary install --binary <path-to-binary>
codepilot binary where
```

### 4.2 发布目录

```bash
codepilot binary release --build-current
codepilot binary verify
codepilot binary prepare --version <版本号>
```

## 5. 排障手册

### 5.1 命令不存在（旧入口）

现象：提示 `命令 xxx 已移除`

处理：

- `show/logs/stop/retry/find/...` 改为 `task <subcommand>`
- `release ...` 改为 `binary ...`
- `webui ...` 改为 `ui <start|status|logs|stop|restart>`

### 5.2 任务卡住或无输出

顺序建议：

1. `codepilot status -p <项目名> -v`
2. `codepilot task logs <task_id> --full`
3. 必要时 `codepilot task stop <task_id>`
4. 修复后 `codepilot task retry <task_id>`

### 5.3 环境检查

```bash
codepilot doctor
codepilot doctor --json
```

## 6. 结构化调用契约

命令支持统一 envelope：

```json
{
  "ok": true,
  "command": "status",
  "data": {}
}
```

失败时会包含 `error` 字段（`message` / `code`）。
